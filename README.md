# Menu Bar Cleaner

メニューバーのアイコンのうち、必要なものだけを常に表示し、それ以外を隠すmacOSのアプリ。隠したアイコンは、クリック1回かショートカットで呼び出せる。

設定の画面はない。並べ替えはmacOSの標準の⌘ドラッグで行い、それ以外の操作はメニューバーのボタンとその右クリックのメニューで済む。

## 使い方

1. ⌘キーを押したまま、隠したいアイコンを区切り`|`より左へドラッグする
2. `‹`をクリックするか⌃⌥⌘Bを押すと、隠したアイコンが現れる。もう一度押すと隠れる
3. 現れたアイコンは、15秒たつと自動で隠れる（右クリックのメニューで切り替えられる）

区切りは、トグル`‹`より左に置く。右にあると、隠したときにトグル自体も隠れるため、隠す操作を止めて案内を出す。

### 右クリックのメニュー

| 項目 | 内容 |
| --- | --- |
| 隠した項目を表示／項目を隠す | クリックと同じ |
| 隠れている項目 | 区切りより左にある項目の一覧。選ぶと、その項目をクリックしたのと同じ操作をする。ノッチの裏で見えない項目もここから開ける（アクセシビリティの許可が必要） |
| 15秒後に自動で隠す | 自動で隠すかどうか |
| ショートカット⌃⌥⌘B | ショートカットを使うかどうか |
| ログイン時に起動 | ログイン項目への登録 |

設定は再起動後も残る。どのアイコンを隠すか（区切りの左右どちらにあるか）は、macOSが状態アイコンの位置として保存する。

## 動かす

必要なもの：macOS 13以降、XcodeかCommand Line Tools（Swift 5.9以降）。

```bash
./scripts/build-app.sh
open "build/Menu Bar Cleaner.app"
```

ログイン時に起動させるときは、`build/Menu Bar Cleaner.app`を`/Applications`などに移してから、メニューの「ログイン時に起動」を選ぶ。登録した後に`.app`を動かすと、起動しなくなる。

開発のときは、`swift run`でも起動できる。ただし`.app`ではないため、「ログイン時に起動」は選べない。

## 必要な権限

| 権限 | 使う機能 | 許可しないとき |
| --- | --- | --- |
| なし | 隠す、表示する、ショートカット、自動で隠す、ログイン時の起動 | ― |
| アクセシビリティ | 「隠れている項目」の一覧 | 一覧の代わりに、許可を求める項目を出す。ほかの機能は動く |

許可は、システム設定→プライバシーとセキュリティ→アクセシビリティで「Menu Bar Cleaner」をオンにする。

アドホック署名でビルドしているため、ビルドし直すと許可が外れることがある。そのときは一覧から「Menu Bar Cleaner」を消して、許可し直す。

画面収録と入力監視の権限は使わない。データを外部に送らない。

## 既知の制約

- **隠す仕組み**：区切りの状態アイコンを横に長くして、その左のアイコンを画面の外へ押し出す（[hidden](https://github.com/dwarvesf/hidden)と同じ方式）。公開APIだけを使うが、macOSの更新で動かなくなるおそれがある。macOS 27のベータでは動かないという報告がある（未確認）
- **動かせない項目**：時計とコントロールセンターは⌘ドラッグで動かせないため、隠せない
- **新しいアイコン**：あとから起動したアプリのアイコンが区切りより左に現れると、最初から隠れる。区切りの右へ⌘ドラッグすれば表示される
- **ノッチ**：展開したとき、アイコンが多いとノッチの裏に入って見えないことがある。その項目は「隠れている項目」から開く。一覧では名前とアプリのアイコンしか出ない（項目そのものの画像は出さない）
- **「隠れている項目」から開く操作**：AXPress（通常のクリックに当たる操作）を送るため、右クリックでだけ出るメニューは開けない。開いたメニューがどこに出るかは、アプリごとに確かめていない
- **複数のディスプレイ**：主に1台で確かめた。外部ディスプレイでの動きは確かめていない
- **ショートカット**：⌃⌥⌘Bに固定。ほかのアプリが先に使っていると登録できず、メニューに「（使用できません）」と出る

調査の詳細と判断の理由は[docs/research.md](docs/research.md)にある。

## 開発

| 用途 | コマンド |
| --- | --- |
| ビルド | `swift build` |
| テスト | `swift test` |
| .appを作る | `./scripts/build-app.sh` |

```text
Sources/
  MenuBarCleaner/        アプリ本体（AppKit）
    StatusBarController  トグルと区切り、メニュー、展開と折りたたみ
    MenuBarItems         Accessibility API で他アプリの項目を読む（OS に依存する部分）
    HotKey               グローバルショートカット
    LoginItem            ログイン時の起動
    Settings             UserDefaults の設定
  MenuBarCleanerCore/    OS に依存しない判定（テストの対象）
Tests/                   MenuBarCleanerCore のテスト
```
